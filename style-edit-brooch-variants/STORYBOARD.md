## 3. Storyboard

### V1 — "Problem → Tembus" (~57s)
**D → E** → A → B → C → F → G → H → I → K
- 0s buka dengan masalah: "bahagian banyak layer… tapi yang ini tidak" → terus demo "walaupun tebal, tembus!".
- Selepas itu cerita asal mengalir (A–C), tutup dengan "masuk mesin pun tak tanggal".

### V2 — "Jarum Tajam" (~57s)
**C (mula dari "tengok…")** → D → E → A → B → F → G → H → I → K
- 0s close-up jarum panjang & tajam: "Tengok, sangat-sangat tajam, senang gila nak cucuk. Nampak tak?" — visual paling tajam untuk stop scroll.

### V3 — "Masuk Mesin" (~57s)
**K** → A → B → C → D → E → F → G → H → I
- 0s claim mengejut: "Masuk mesin pun dia tak tanggal weh!" sambil tunjuk set brooch → baru terangkan kenapa.

## 4. Gaya (ikut style brooch sekarang, tapi lebih lembut)
- Font: Lexend Mega 600, putih, bayang nipis (hook 34px, kata kunci 30px) + garis kecil bawah.
- **Motion slow**: zoom perlahan 1.00 ↔ 1.05 sepanjang setiap segmen (sine), setiap cut masuk dengan settle lembut 1.03 → 1.00 (1.2s). Tiada punch zoom.
- Teks: fade + naik perlahan 0.7s (`power2.out`), keluar fade 0.45s.
- **SFX lembut** (volume 0.12–0.2): soft chime untuk kata kunci, air-whoosh perlahan masa cut, bell lembut untuk hook. Tiada boom / coin / cork.
- Audio cut: fade 30ms setiap sambungan supaya tiada bunyi "klik".
